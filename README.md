# CCTV Layout Planner Pro

A lightweight 2D surveillance design application for security integrators, consultants, and IT project teams. Load architectural PDFs, draw blocking walls for accurate shadow-mapping, and automatically generate AutoCAD DXF files and inventory schedules.

## 🚀 Quick Start (From Source)
If you prefer to run the application from the raw source code:
1. Install [Python 3.10+](https://www.python.org/downloads/)
2. Clone this repository and install dependencies:
